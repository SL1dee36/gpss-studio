# Система сборки GPSS/H Studio (Nuitka Builder)

Данная директория содержит автоматизированные скрипты для компиляции **GPSS/H Studio** в автономный исполняемый `.exe` файл для Windows с помощью компилятора **Nuitka**.

---

## ⚡ Быстрый запуск

### Вариант 1 (Windows, в 1 клик):
Просто запустите двойным щелчком файл **`build.bat`**.

### Вариант 2 (Через командную строку / терминал):
```bash
python builder/build.py
```

---

## ⚙️ Параметры скрипта `build.py`

| Флаг | Описание |
|---|---|
| `--mode onefile` | *(По умолчанию)* Компиляция в **один самостоятельный файл `gpss-studio.exe`**. Все зависимости (Qt/PySide6) упакованы внутри. |
| `--mode standalone` | Компиляция в папку `dist/gpss-studio.dist/` со всеми `.dll` и библиотеками без упаковки в один файл (удобно для быстрой отладки сборки). |
| `--clean` | Автоматически удалить промежуточные папки кэша компиляции (`.build`, `.onefile-build`) после завершения сборки. |
| `--no-root-copy` | Не копировать итоговый файл `gpss-studio.exe` в корень проекта (оставить только в `builder/dist/`). |

### Примеры:
```bash
# Сборка одного файла .exe с очисткой временных файлов
python builder/build.py --clean

# Быстрая сборка в папку standalone
python builder/build.py --mode standalone
```

---

## 📋 Требования для сборки

1. **Python 3.8+** (рекомендуется Python 3.11 или 3.12).
2. **PySide6**:
   ```bash
   pip install PySide6
   ```
3. **Nuitka и zstandard**:
   ```bash
   pip install nuitka zstandard
   ```
4. **C-компилятор**:
   - На Windows Nuitka автоматически использует **MinGW64 gcc** или **MSVC**.
   - При первом запуске Nuitka может предложить автоматически загрузить MinGW64 (скрипт передает флаг `--assume-yes-for-downloads`, поэтому подтверждение произойдет автоматически).

---

## 📂 Результаты сборки

- Готовый исполняемый файл размещается по пути:  
  `builder/dist/gpss-studio.exe`  
  и автоматически дублируется в корень репозитория:  
  `gpss-studio.exe`.
- Собранный файл можно запускать напрямую, он готов к работе рядом с `gpssh.exe` и `settings.json`.
